# Acornia requirements review

Prepared by Tranquil Veda. This public site contains a sanitized, versioned scope review based on discussion recording 135. It does not include the recording, transcript, private comments or credentials.

Each review item has a stable ID, revision and content hash. Proposed acceptance checks and open questions are explicit. All items start pending review.

## Reviewing

1. Read a requirement and select a decision. Add the requested change or comment.
2. Copy the prepared review batch and open the private GitHub submission page.
3. Paste the batch and submit it on GitHub. The private GitHub record is the durable submission.

Device drafts are not shared approvals. This static page cannot verify private submissions automatically. The reviewer must have access to the separate private review repository. No privileged token is included in the public site.

Approvals apply only to the exact reviewed revision. Changes to scope require re-approval. Completing review does not start implementation, update the existing tracker or deploy the application.

## Publication

Only `index.html`, `style.css`, `review.js`, `requirements.json`, `.nojekyll` and this README belong in the public repository. Private records and source material must not be added.
